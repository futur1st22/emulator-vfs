# Эмулятор командной строки с VFS (вариант 11)

## Описание

Консольный эмулятор командной строки UNIX-подобной ОС на Python 3.
Приглашение к вводу содержит имя VFS, например `minimal$ `.

## Параметры запуска

- `--vfs ПУТЬ` — путь к VFS. Имя файла без расширения выводится
  в приглашении. Без параметра используется `default_vfs`.
- `--script ПУТЬ` — стартовый скрипт с командами эмулятора.

При запуске выводятся все заданные параметры.

## Команды

- `ls`, `cd` — заглушки, выводят имя команды и аргументы.
- `exit` — выход из эмулятора.

На неизвестную команду выводится `command not found`.

## Стартовый скрипт

Одна команда на строку, комментарии начинаются с `#`. Команды выводятся
на экран вместе с результатом. Если в строке ошибка, выводится ее номер,
и скрипт продолжает работу.

```
# пример скрипта
ls -la /home
cd docs   # комментарий
exit
```

## Запуск и тесты

```
run.bat --vfs vfs\minimal.zip --script scripts\basic.txt
py -m unittest discover -s tests
```

Скрипты для проверки параметров: `scripts\test_basic.bat`,
`scripts\test_errors.bat`, `scripts\test_interactive.bat`.

## Пример

```
default_vfs$ ls -la /home
ls: -la /home
default_vfs$ foo
emulator: command not found: foo
default_vfs$ exit
```
